Featured work

Computer vision · accessibility

Shravan

Real-time assistive object detection and voice guidance for visually impaired indoor navigation. A custom-trained YOLO11n model detects household obstacles from a live webcam feed; the system maps each detection to left/ahead/right and announces it through an asynchronously threaded Windows SAPI voice engine, so the video feed never freezes while it's speaking.

  • Custom-annotated dataset on top of Ultralytics houseobject4k
  • 74.97% precision · 66.73% recall · 72.71% mAP@0.5
  • OpenCV · threading · Windows SAPI via COM

Recommender systems

Anime recommendation system

Content-based recommender over 39,380 titles from the Manami Project's Anime Offline Database, using TF-IDF over standardized genre/tag taxonomy and cosine similarity. Precomputing the full similarity matrix demanded 12.4GB of RAM and crashed on standard hosting — solved by switching to on-the-fly similarity calculation against a sparse matrix, cutting background memory to near zero.

  • TF-IDF vectorization + cosine similarity
  • Solved a 12.4GB OOM bottleneck with sparse on-the-fly computation
  • Streamlit frontend with alias-filtering for 100k+ non-ASCII titles
